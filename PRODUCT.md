# Pawprint MVP

Pawprint turns a walk into an ethical shared field guide: discover nearby animals, log a calm sighting, review AI duplicate suggestions, grow a living 2D/3D memory, and build companionship through real movement.

## Core journeys

1. Discover privacy-softened community sightings.
2. Capture from a safe distance; never chase or use flash.
3. Review an explainable visual/location similarity suggestion before merging.
4. Care for a 2D companion and revisit the 3D memory.
5. Walk to improve happiness and unlock journal rewards.
6. Moderate welfare flags, sensitive locations, and duplicate profiles.

## Production path

- TypeScript/Next.js installable PWA first; Capacitor wrapper later for app stores and background GPS.
- PostgreSQL/PostGIS, object storage, Redis geospatial cache, and reversible merge history.
- Versioned image embeddings plus time/distance scoring and human confirmation.
- Guided multi-angle capture to an asynchronous photogrammetry/Gaussian-splat pipeline, exported as GLB/glTF for web/native AR.
- Authentication, consent, abuse reporting, audit logs, encryption, deletion/export, welfare escalation, and local privacy review before launch.
